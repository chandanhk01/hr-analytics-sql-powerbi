# HR Analytics Dashboard | SQL + Power BI

## 📊 Project Overview

This project is an end-to-end HR Analytics project developed using SQL Server and Power BI.

The project focuses on analyzing employee data to understand workforce distribution, salary patterns, attrition, and employee performance.

## 🎯 Objectives

- Analyze employee demographics and workforce distribution
- Understand salary and payroll patterns
- Analyze employee attrition
- Evaluate employee performance
- Create an interactive HR Analytics dashboard

## 🛠️ Tools & Technologies

- SQL Server
- SQL
- Power BI
- DAX
- Power Query

## 🔄 Project Workflow

1. Imported the HR dataset into SQL Server
2. Performed data cleaning and validation using SQL
3. Checked NULL values and duplicate records
4. Analyzed employee and performance data
5. Created relationships between employee and performance tables
6. Connected the cleaned SQL tables directly to Power BI
7. Created DAX measures for KPIs
8. Designed an interactive HR Analytics dashboard

## 📈 Dashboard Features

- Total Employees
- Total Monthly Payroll
- Attrition Rate
- Average Manager Rating
- Employee distribution by State
- Average Salary by Department
- Attrition Rate by Gender
- Payroll by State
- Interactive slicers for filtering the dashboard
- Clear All button to reset filters
